# پل TrendPilot سمت MT5 — نسخه‌ی پایتون

جایگزین `mt5-ea/TrendPilotBridge.mq5` برای کسانی که ترجیح می‌دهند
مثل قبل با پایتون کار کنند. برخلاف EA (که باید per-symbol روی هر
چارت جداگانه نصب شود)، این یک **پروسه‌ی واحد** است که با پکیج رسمی
`MetaTrader5` مستقیماً به ترمینال وصل می‌شود و همه‌ی نمادهای یک
پروفایل را در یک حلقه پوشش می‌دهد.

مثل EA، این اسکریپت هم **هیچ محاسبه یا تصمیمی نمی‌گیرد** — فقط کندل
می‌فرستد، دستور سرور را می‌خواند، و با `mt5.order_send` اجرا می‌کند.

## نیازمندی‌ها

- **ویندوز** (پکیج `MetaTrader5` فقط روی ویندوز کار می‌کند — چون به‌طور
  مستقیم به فایل‌های ترمینال MT5 نصب‌شده روی همان سیستم وصل می‌شود)
- پایتون ۳.۹ به بالا
- ترمینال MT5 نصب و باز باشد (لاگین دستی، یا اسکریپت خودش لاگین کند)

## نصب و اجرا

```bash
cd mt5-bridge-python
pip install -r requirements.txt
cp .env.example .env
# .env را با ادیتور باز کنید و مقداردهی کنید:
#   SERVER_BASE_URL, PROFILE_NAME, SYMBOLS, TIMEFRAME_MINUTES
python bridge.py
```

## تنظیمات مهم در `.env`

| متغیر | توضیح |
|---|---|
| `SERVER_BASE_URL` | آدرس سرور TrendPilot |
| `PROFILE_NAME` | باید دقیقاً با نام پروفایلی که در وب UI ساخته‌اید یکی باشد |
| `SYMBOLS` | لیست نمادها با کاما جدا شده — باید با نمادهای همان پروفایل یکی باشد |
| `TIMEFRAME_MINUTES` | باید با `TIMEFRAME` تنظیم‌شده در پروفایل یکی باشد |
| `MT5_LOGIN/PASSWORD/SERVER` | اختیاری — اگر خالی بگذارید، از ترمینالی که از قبل لاگین است استفاده می‌شود |

## تفاوت با EA (MQL5)

| | EA (`mt5-ea/`) | پل پایتون (این پوشه) |
|---|---|---|
| نصب | per-symbol (روی هر چارت جدا) | یک‌بار، یک پروسه برای همه‌ی نمادها |
| اجرا | داخل خودِ ترمینال MT5 | پروسه‌ی جداگانه (می‌تواند به‌صورت سرویس/task زمان‌بندی‌شده هم اجرا شود) |
| نیازمندی | فقط Allow WebRequest + Algo Trading | پایتون + پکیج MetaTrader5 |
| مناسب برای | کسانی که راحت‌تر با محیط MT5 کار می‌کنند | کسانی که از قبل با پایتون کار می‌کردند |

هر دو را می‌توانید داشته باشید، ولی برای یک پروفایل فقط از **یکی**
استفاده کنید (اجرای هم‌زمان هر دو روی یک نماد باعث ارسال کندل تکراری
و پردازش دوبار می‌شود — بی‌ضرر ولی غیرضروری).

## چند پروفایل هم‌زمان

برای هر پروفایل، یک نمونه‌ی جداگانه از `bridge.py` (با `.env` جدا یا
متغیرهای محیطی متفاوت) اجرا کنید — یا فایل را کپی کرده و
`PROFILE_NAME`/`SYMBOLS` را در هرکدام جدا تنظیم کنید.

## اجرای دائمی و خودکار (بدون باز نگه‌داشتن پنجره‌ی دستی)

سه فایل کمکی اضافه شده تا نیازی به اجرای دستی `python bridge.py` هر بار نباشد:

### روش ۱ — نصب یک‌کلیکی خودکارسازی (پیشنهادی)

1. روی `install_autostart.bat` **راست‌کلیک** کنید → **Run as administrator**
2. همین. از این به بعد:
   - با هر بار روشن شدن/لاگین ویندوز، پل TrendPilot خودکار و **بدون نمایش
     پنجره‌ی کنسول** در پس‌زمینه اجرا می‌شود
   - لاگ‌ها همیشه در فایل `bridge.log` (کنار `bridge.py`) نوشته می‌شوند —
     برای بررسی وضعیت، همین فایل را باز کنید
   - اگر پایتون یا اسکریپت کرش کند، خودِ اسکریپت (طبق منطق تلاش‌مجدد
     داخلی‌اش) دوباره وصل می‌شود، بدون نیاز به دخالت شما

برای اجرای فوری همین الان (بدون نیاز به لاگین مجدد ویندوز)، در Command
Prompt بزنید:
```
schtasks /Run /TN "TrendPilotBridge"
```

برای **متوقف کردن** اجرای خودکار: `uninstall_autostart.bat` را اجرا کنید
(نیازی به Administrator ندارد، ولی بهتر است با آن اجرا شود).

### روش ۲ — دستی از طریق Task Scheduler ویندوز (اگر ترجیح می‌دهید با GUI کار کنید)

1. `Win + R` → بنویسید `taskschd.msc` → Enter
2. **Create Task** (نه Create Basic Task) در پنل سمت راست
3. تب **General**: نامی بدهید (مثلاً `TrendPilotBridge`)؛ **Run whether
   user is logged on or not** یا **Run only when user is logged on**
   را بسته به نیازتان انتخاب کنید
4. تب **Triggers** → **New** → **At log on**
5. تب **Actions** → **New** → Program/script: `wscript.exe` →
   Arguments: مسیر کامل `run_hidden.vbs` (مثلاً
   `"C:\TrendPilot\mt5-bridge-python\run_hidden.vbs"`)
6. **OK** را بزنید

### روش ۳ — سرویس واقعی ویندوز (برای اجرا حتی بدون لاگین کاربر)

اگر می‌خواهید حتی وقتی هیچ‌کس وارد ویندوز نشده هم اجرا شود (مناسب VPS
بدون رابط گرافیکی دائم)، از ابزار رایگان [NSSM](https://nssm.cc/) استفاده
کنید:
```
nssm install TrendPilotBridge "C:\Python3\python.exe" "C:\TrendPilot\mt5-bridge-python\bridge.py"
nssm set TrendPilotBridge AppDirectory "C:\TrendPilot\mt5-bridge-python"
nssm start TrendPilotBridge
```
توجه: چون ترمینال MT5 معمولاً به یک session گرافیکی نیاز دارد، این روش
عمدتاً وقتی مفید است که MT5 هم به‌صورت خودکار در همان session بالا بیاید
(یا از یک VPS با auto-logon استفاده کنید).
